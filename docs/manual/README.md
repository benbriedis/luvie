# Luvie manual

A free pattern-based MIDI sequencer for Linux, macOS and Windows.

This manual is written for people using Luvie. Notes about building it are in
[`BUILD`](../../BUILD); notes about how it is put together are in
[`NOTES/`](../../NOTES).
